Cross-Device Sync

Connect a GitHub Gist as private cloud storage so your phone and computer share the same data.

  1. Go to github.com/settings/tokens/new (GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)).
  2. Name it anything, set an expiration you're comfortable with, and check only the gist scope — nothing else.
  3. Generate it, copy the token, and paste it below.

The token is stored only in this browser and used to talk directly to GitHub's API — it never touches this app's source or repo. Do the same on your other device with the same token to link them.
